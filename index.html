Generative surrogate models and inverse design for PCB power deliveryGenerative Surrogatmodelle und Inverse Design für die Stromversorgung von Leiterplatten

PCB power-delivery networks are normally checked with slow physics simulations. I built a generative surrogate that predicts the behaviour quickly, and an inverse-design step that proposes a layout for a given performance target.Power-Delivery-Netzwerke auf Leiterplatten werden üblicherweise mit langsamen Physiksimulationen geprüft. Ich habe ein generatives Surrogatmodell gebaut, das das Verhalten schnell vorhersagt, und einen Inverse-Design-Schritt, der für ein vorgegebenes Leistungsziel ein Layout vorschlägt.

What I builtWas ich gebaut habe

  • Multimodal product-of-experts VAE in PyTorch as a generative surrogate that replaces slow physics simulations.Multimodaler Product-of-Experts-VAE in PyTorch als generatives Surrogat, das langsame Physiksimulationen ersetzt.
  • Gradient-based inverse design in the latent space: it starts from a performance target and returns a candidate layout directly. The result is fast and practical, not provably optimal.Gradientenbasiertes Inverse Design im Latentraum: Es geht von einem Leistungsziel aus und liefert direkt ein Kandidaten-Layout. Das Ergebnis ist schnell und praxistauglich, aber nicht beweisbar optimal.
  • Trained on 29,499 PCB layouts and 688,477 layout–frequency pairs. The split keeps every design on one side only, so the test measures generalisation to unseen designs.Trainiert auf 29.499 Leiterplatten-Layouts und 688.477 Layout-Frequenz-Paaren. Die Aufteilung hält jedes Design nur auf einer Seite, sodass der Test die Generalisierung auf unbekannte Designs misst.
  • Distributed training with PyTorch DDP and CUDA on multiple GPUs. Training is fault-tolerant: checkpoint resume, gradient clipping and NaN guards.Verteiltes Training mit PyTorch DDP und CUDA auf mehreren GPUs. Das Training ist fehlertolerant: Checkpoint-Resume, Gradient Clipping und NaN-Prüfungen.
  • All experiments are tracked and visualised in MLflow.Alle Experimente werden in MLflow erfasst und visualisiert.
  • Served as a FastAPI inference service with health and prediction endpoints, packaged in Docker. pytest, schema validation and GitHub Actions check every code change.Bereitgestellt als FastAPI-Inferenzdienst mit Health- und Prediction-Endpunkten, verpackt in Docker. pytest, Schema-Validierung und GitHub Actions prüfen jede Codeänderung.
