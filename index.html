PDN Design Assistant: generative AI for PCB power deliveryPDN Design Assistant: generative KI für die Stromversorgung von Leiterplatten

Engineers keep a board's supply impedance under a target by placing decoupling capacitors, and every candidate layout normally needs a slow field-solver run. My thesis replaces that loop with a generative surrogate, an inverse-design search and a web app that checks and fixes layouts live, with the solver still in the loop to confirm the result.Ingenieure halten die Impedanz der Versorgung unter einem Zielwert, indem sie Entkoppelkondensatoren platzieren, und jedes Kandidaten-Layout braucht normalerweise einen langsamen Feldlöser-Lauf. Meine Masterarbeit ersetzt diese Schleife durch ein generatives Surrogatmodell, eine Inverse-Design-Suche und eine Web-App, die Layouts live prüft und verbessert, wobei der Löser das Ergebnis weiterhin bestätigt.

  • A product-of-experts VAE with graph encoders over the 52-slot board, a spectrum encoder and a FiLM-conditioned CNN map decoder. A second, placement-only encoder predicts spectrum and map from the layout alone, the path available at design time.Ein Product-of-Experts-VAE mit Graph-Encodern über die 52 Bestückungsplätze, einem Spektrum-Encoder und einem per FiLM konditionierten CNN-Decoder für die Karte. Ein zweiter Encoder sagt Spektrum und Karte allein aus der Bestückung vorher, also genau das, was beim Entwurf verfügbar ist.
  • 30,000 simulated layouts from a batched, resumable eCADSTAR pipeline, about 100 hours of solver time.30.000 simulierte Layouts aus einer gebündelten, fortsetzbaren eCADSTAR-Pipeline, rund 100 Stunden Löserzeit.

  • The ML system around it: a 13-stage, config-driven pipeline, two-GPU DDP training, MLflow tracking, multi-stage Docker images, GitHub Actions CI and 116 data-free tests.Das ML-System drumherum: eine konfigurationsgesteuerte Pipeline mit 13 Stufen, DDP-Training auf zwei GPUs, MLflow-Tracking, mehrstufige Docker-Images, GitHub-Actions-CI und 116 datenfreie Tests.

Night-time camera + LiDAR fusion: does LiDAR help in the dark?Kamera + LiDAR bei Nacht: Hilft LiDAR im Dunkeln?

One network that finds road users and estimates how far away each one is, trained on nuScenes twice, from the front camera alone and with projected LiDAR, and compared on day and night scenes with proper uncertainty. LiDAR roughly halves the distance error: 8.1 % → 4.3 %, and at night 10.9 % → 3.6 %.Ein Netz, das Verkehrsteilnehmer findet und deren Entfernung schätzt, zweimal auf nuScenes trainiert, einmal nur mit der Frontkamera und einmal mit projiziertem LiDAR, und auf Tag- und Nachtszenen mit sauberer Unsicherheitsangabe verglichen. LiDAR halbiert den Entfernungsfehler ungefähr: 8,1 % → 4,3 %, nachts 10,9 % → 3,6 %.

An agent that detects a failure in a running microservice system, investigates it with read-only tools and proposes the fix as a pull request. A human approves, and GitOps deploys it. An evaluation pipeline will measure how well it does on local models and on a paid API. Work in progress: nothing here claims a result that has not been measured.Ein Agent, der einen Fehler in einem laufenden Microservice-System erkennt, ihn mit rein lesenden Tools untersucht und die Korrektur als Pull Request vorschlägt. Ein Mensch gibt frei, GitOps rollt aus. Eine Evaluationspipeline soll messen, wie gut er mit lokalen Modellen und mit einer kostenpflichtigen API abschneidet. In Arbeit: Hier wird kein Ergebnis behauptet, das nicht gemessen wurde.
